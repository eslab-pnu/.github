# ESLab @ PNU

부산대학교 ESLab의 연구 자료를 안내한다. 온디바이스 AI, 경량 언어·음성·비전 모델, 센서 기반 행동 인식과 이상탐지를 연구한다.

## 연구 자료와 협업

연구 코드와 실험 설정은 주제별 저장소에서, 개인 연구는 `research-*`에서 관리한다. 주간보고·세미나·회의 기록은 연구 진행과 근거를 연결한다.

[구성원용 안내](https://github.com/eslab-pnu/.github-private) · [연구실 운영 규칙](https://github.com/eslab-pnu/lab-guidelines) · [세미나 기록](https://github.com/eslab-pnu/lab-seminars) · [졸업생 연구](https://github.com/eslab-pnu/alumni)

구성원 자료는 private 저장소에서 관리하며 열람에는 해당 저장소의 접근 권한이 필요하다.
